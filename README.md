# Learning JavaScript 🚀

Welcome to my **JavaScript learning journey**! This repository documents my growth from fundamentals to intermediate and advanced topics. I’m building hands-on examples, mini projects, and experiments to deeply understand how JavaScript works in real-world applications.

---

## 🧩 What’s Inside

- **Core Concepts & Tutorials**  
  Files and scripts covering basic to intermediate topics — variables, loops, functions, scoping, closures, callbacks, promises, async/await, etc.

- **DOM & Browser APIs**  
  Projects demonstrating DOM manipulation, event handling, dynamic UI updates, form handling, localStorage, and browser API usage.

- **Mini Projects & Challenges**  
  Small practical applications (e.g. calculators, to-do lists, image sliders, interactive forms) to solidify learning.

- **Advanced Topics & Experiments**  
  Exploring modules, ES6+ features, error handling, fetch/axios for HTTP, and integrating vanilla JavaScript in real scenarios.

- **Utility & Practice Files**  
  Support files like `utils.js`, testing scripts, code snippets, and experiment files to reinforce concepts.

---

## 💡 Why This Repo Exists

- To **learn by doing**: Theory matters, but applying it in projects helps retention.  
- To **share progress**: Anyone can follow along, learn, fork, or contribute.  
- To build a **solid JavaScript foundation** before diving deeper into frameworks or full-stack development.

---

## 📚 Tech & Tools

- **Core Language**: JavaScript (ES6+)  
- **HTML / CSS**: For building interfaces around JavaScript logic  
- **Browser APIs**: DOM, Fetch, localStorage, Event APIs  
- **Tooling**: VS Code, browser dev tools, console debugging  
- **Future Upgrades**: Bundlers (Webpack, Vite), testing frameworks (Jest), TypeScript
